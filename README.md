# свой брокер сообщений

Пишем лёгкий брокер сообщений с нуля, чтобы тестовые сервисы общались асинхронно: один публикует, остальные подписаны на топики.


### Что точно будет работать
- pub/sub по **топикам** (модель как у Kafka)
- сообщения в append-only **журнале на диске** — не теряются после рестарта
- at-least-once доставка (по мере реализации этапа 3)
- клиентская библиотека на Python
- STOMP over WebSocket
- Prometheus метрики
- приоритеты, TTL, DLQ

### Как запустить (в итоге)
```bash
docker compose up --build
```
